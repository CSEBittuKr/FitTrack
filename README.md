## About

FitTrack is a premium responsive fitness and habit-tracking web experience designed to help users track daily activity, habits, and personal goals through an interactive dashboard.

## Features

* Premium responsive landing page
* Interactive fitness dashboard
* Habit tracking
* Daily activity and goal progress
* Overview, Habits and Activity tabs
* Responsive mobile navigation
* Smooth micro-interactions
* Easter egg interaction

## Tech Stack

* HTML5
* CSS3
* Vanilla JavaScript
* SVG
* Vercel
